## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
doc-10 の設計。現行は台帳管理画面（TASK-39、`ProjectLedger.svelte`）とプロジェクト管理画面（TASK-40、`ProjectManage.svelte`）が別々にあり、前者は全プロジェクトの台帳、後者は 1 プロジェクトの文書・マイルストーン・新規タスクという異なる粒度を並べている。利用者は同じプロジェクトを扱うのに 2 画面を行き来する。粒度を 1 プロジェクトへ揃え、そのプロジェクトに対してできることを 1 画面へ集める。

台帳読取専用（doc-3 §2.2）と CLI 縮退（doc-5 §5）は独立に扱う。台帳操作は CLI を使わないため CLI 縮退でも動き、逆に台帳が読み取り専用でも文書・マイルストーン・新規タスクは発行できる。提供しない操作（文書の削除・マイルストーンの説明編集・改称／削除／アーカイブ）は、押せないボタンとして並べず、名称・写像先・理由の 3 点で並べる。
