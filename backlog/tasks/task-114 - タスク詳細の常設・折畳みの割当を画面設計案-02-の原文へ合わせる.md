## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
画面設計案 02 の中央モーダルと全面シングルビューの原文が、doc-8 §3 の割当表と食い違っている。原文は全面シングルビューでも `▼実装計画`・`▼実装ノート`・`▼REFERENCES`・`▼状態遷移`・`▼外部エディタで開く` に開閉印を描いており、これらは開いた折畳みである（開閉印を持つのは折畳みの区画だけ。doc-8 §3・TASK-73）。中央モーダルの図でも `▼実装計画`・`▼REFERENCES` が開閉印を持つ。

これは doc-8 §2.1 の「全面シングルビューはスイムレーンを退け、全区画を常設で出す」と正面から衝突し、doc-8 §3 の割当表が実装計画とReferences を中央モーダルで常設としている行とも食い違う。

2026-08-04 に TASK-113 の原文提示で判明した。TASK-73 の目視では「全面に折畳みが無いのは doc-8 §2.1・§3 のとおり」と仕様として答えていたが、その回答はこの原文で覆る。TASK-113 は並び・列構成・行長だけを扱い、常設と折畳みの割当には触れていないので別タスクとする。決定先行タスクであり、doc-8 §2.1 の一文と §3 の割当表の両方を改訂することになる。
