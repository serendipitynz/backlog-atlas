## Implementation Notes

## 確定した契約（2026-08-05・ユーザーが画面設計案 02 の 3 図を提示して確定）

**折畳みの区画は 3 配置とも同じ 4 行**（実装計画・実装ノート・References・状態遷移/外部エディタ）で、
配置によって常設と折畳みを行き来する区画は無い。配置で変わるのは**既定開閉**だけ。

| 区画 | 併置 | モーダル | 全面 |
|---|---|---|---|
| 実装計画 | 折畳み・既定閉 | 折畳み・既定開 | 折畳み・既定開 |
| 実装ノート | 折畳み・既定閉 | 折畳み・既定閉 | 折畳み・既定開 |
| References | 折畳み・既定閉（件数） | 折畳み・既定開 | 折畳み・既定開 |
| 状態遷移・外部エディタ | 折畳み・既定閉 | 折畳み・既定閉 | 折畳み・既定開 |

根拠は原文そのもので、意図的に外れる項目は無い。ユーザーが「図の初期値＝既定の状態」を確定した。

doc-8 §3 が「折畳み」の定義に「既定で閉じた状態」を束ねていたのが食い違いの原因で、束をほどいて
割当表のセルを 3 値（常設 / 折畳み・既定開 / 折畳み・既定閉）へ広げた。doc-8 §2.1 の「全面は全区画を
常設で出す」は「全区画を開いた状態で出す」へ改訂（畳めるが既定で開く）。**decision は書いていない。**

## doc-12 §3 の転記の誤り 3 件（同時に訂正）

1. 初回転記の「状態遷移・外部エディタは全面で常設」は誤り（全面の図は開閉印を持つ）。当時 全面の図は
   転記されておらず、doc-8 の割当表を写していた。
2. TASK-73 の「`▼` 実装計画・`▶` 実装ノート」は併置の図の記述として書かれていたが、その組み合わせを
   持つのは**中央モーダルの図**（併置は実装計画も `▶`）。
3. TASK-113 の「実装計画が折畳みだからその図は併置と決まる」という推定も外れ（実装計画は 3 図とも折畳み）。
   並びの読み取りは 3 図とも同じなので doc-8 §3.1 の正本は動かない。

図が省いている区画も記録した（併置に DESCRIPTION が無く、全面に DESCRIPTION・TYPE・通常ラベルが無い）。
割当は動かさない。
