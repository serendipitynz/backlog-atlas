## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
AC を 2 度直した。理由を残す。

**旧 AC #1・#3 が指していた「実装状況」を README から削除した**（2026-08-13、ユーザーの指示）。
旧 #1 は「実装状況が現在の Backlog の値と一致している」、旧 #3 は「リリース時に README の実装状況を
確認する手順」を求めていたが、ユーザーの判断は「状態」の節そのものが不要（利用者はこれを読んで何に
気をつければよいのか答えられない。追跡が要るなら backlog のタスクと docs/decisions が持つ）だった。
節を消すと旧 #1 は空虚に真になり、旧 #3 は存在しない対象の確認手順を求めることになるため、2 件を
外し、#4（実装されていない機能を実装済みとして述べていない・実装状況の節を持たない）と
#5（README の記述を出荷ビルドと突き合わせる手順）へ置き換えた。#5 の置き場は AGENTS.md /
AGENTS.ja.md の「リリース」節である。

**#6〜#9 はユーザーが 2026-08-13 に出した README 公開可否のフィードバックを AC にしたもの**である。
起票時の Description は「実装状況の更新」だけを対象にしていたが、実際に求められたのは公開向けの
書き直し（先頭の概要・非公式クライアントである旨とリンク・耳慣れない語の除去と 4 節の統合・
ライセンスとコントリビューション）だった。満たしたことにだけして AC を据え置くと、後から読んだ
ときに何が求められていたか分からなくなる。

**「正本」「集約画面」「プロジェクト台帳」は README からのみ外した。** 画面文言の `台帳`（実測で
12 ファイル）と `正本` はユーザーの判断で別タスクへ回した（TASK-158）。対応表は
`_sandbox/handoff/referent-table/referent-table-task-97-90.md` 第 1 版。
