## 判定の軸は decision-41 に書いた

コード註が持ってよいのは **帰属** と **実装固有の理由** の 2 つで、**契約の再記述** は持たない。見分けは
「この文は、この実装が別の形になっても真のままか」— 真のままなら述べているのは契約であって実装ではない。
**述語では分けられない**（契約の再記述も「なぜ」の形で書かれる）ので、why かどうかで判定すると両方が残る。

AGENTS 和英の Coding style / Comments 節がこれを引く。あの節の「既存のコメントを畳むな、提起せよ」は
残し、**提起の答えが decision-41 であること**を足した。**doc-11 §8 は動かしていない** — あの節は自分で
「対象は利用者が読む文だけであり、コードコメントは含まない（そちらは TASK-107）」と書いており、
decision-41 がその外側を引き受けた。

**対応表 初版は decision-41 と AGENTS の改訂より先に、独立した成果物として確定した。** 争点は 2 つ
（AC #1 の字義と表題の「再記述」の差、頭註の 対応表 の扱い）で、どちらもオーナーへ出して答えを得ている。
