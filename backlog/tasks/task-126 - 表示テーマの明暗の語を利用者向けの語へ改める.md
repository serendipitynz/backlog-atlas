## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
**決定先行ではない、と着手時に判定した。** 対応順の理由欄が求めた確認の結果 — decision-12 が定めるのは色値集合・収録テーマ名・収録条件と「既定は OS の明暗に追従」という挙動で、画面に出すラベルの語は定めていない。doc-11 にもテーマのラベル語は無い（§2.1 が持つのは表示テーマの変数名、§8 は散文の落とす／残す）。doc-12 §2.2 の設定モーダル転記はテーマ項目を「草案では Tweaks で切り替え」としか記録しておらず、**原文に選択肢のラベル語が無い** — TASK-122 と違い「原文の語へ戻す」対象が存在しない。よって decision も doc も改訂していない。

**改称したのは画面に出る 2 つの文字列だけである。**`明暗` の語は現に 4 系統の別々の対象を指しており、改称対象はそのうち 2 系統に限る（対応表 `_sandbox/handoff/referent-table-task-126.md` 第 2 版）。

- 収録テーマ 10 件のラベルの括弧内 `（明）／（暗）` → `（ライト）／（ダーク）`（AC #1）
- 未選択の選択肢 `OS の明暗に従う（既定: Atlas Light / Atlas Dark）` → `システム設定に従う`（AC #2）

改称しなかったのは、`RecordedTheme.scheme` と `app.scss` の `color-scheme`（CSS キーワードで画面に出ない）、decision-12 と各コードコメントの「OS の明暗に追従」（挙動の記述）、doc-12 §6.2 の見出し「明暗」と §6.4（画面設計案 05 の転記）である。

**未選択の選択肢からテーマ名 2 つを落とした理由。** この選択肢が選ぶのはシステムに従うという状態であって、その状態が解決する 2 組のどちらかではない。名前を併記すると「押すと Atlas Light になる」と読め、テーマを選んだ状態ならシステムに従うのをやめるので、この選択肢が唯一する仕事と正反対になる。どちらが既定かは 2 組自身のラベルの `・既定` が今も述べている。

**試験で固定した契約は 2 件**（`theme.test.ts`。どちらも壊して落ちることを確認済み）。

- ラベルの `ライト／ダーク` は `scheme` が宣言する側と一致し、反対側の語を含まない。この 2 つを結ぶものは今まで無く、`（ライト）` と `scheme: "dark"` の組み合わせは一覧では正しく読めて反対の地を塗る（decision-12 が収録条件の検算について述べた費用と同じ形）。10 組のうち 4 組（Catppuccin Latte / Mocha、Rosé Pine Dawn / Rosé Pine）は名前が明暗をどちらの言語でも持たないので、括弧内が唯一の手がかりである。
- 未選択の選択肢は収録テーマの id も名前も含まない。

**実測**（借り物 playwright、viewport 1280×800、`_sandbox/settings-check/index.html?modal=settings`。変更前も同じ条件で測った）。

| 保存されている `theme` | エンジン | `<select>` 幅 変更前 → 変更後 |
|---|---|---|
| 未選択 | WebKit | 277 → 180 px |
| 未選択 | Chromium | 321 → 198 px |
| 収録していない名前（`nord`） | WebKit | 277 → 238 px |
| 収録していない名前（`nord`） | Chromium | 321 → 289 px |

`<select>` の高さ（WebKit 18 / Chromium 19）・区画の外形（680×50 / 680×51.2）・モーダル幅（706）は前後とも同値で、区画からのはみ出しは前後とも無い。**ライト／ダーク は 明／暗 より 2 文字長いが、控えは広がらず縮んだ** — 変更前の幅を決めていたのは 10 組のラベルではなく未選択の 1 行だったからで、片側だけ測っていたら「語を長くしたのに縮んだ」を説明できなかった。収録していない名前が保存されている場合の幅を決めているのは `nord（このビルドには収録されていません）` の行で、これは改称の対象ではない。

**ハーネスに `?theme=` を足した**（`_sandbox/settings-check/Harness.svelte`）。記録済み fixture の `theme` が `nord` で、設定画面はそのときだけ「収録されていません」の行を足すため、**収録テーマのラベルの長さが `<select>` の幅に出ない状態でしか測れなかった**。

**測っていないもの**（目視へ回す範囲）: 実機 webview での見え方、`<select>` を開いた後のポップアップ（OS が描くので playwright のスクリーンショットに写らない）、暗いテーマでの読みやすさ。
