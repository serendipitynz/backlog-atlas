## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
2026-08-09 のユーザーフィードバック (`save-button.png`)。機能的に同じ「発行する控え」が 8 か所で 4 通りの置かれ方をしている。

- 左下に単独 — プロジェクト登録モーダル・文書作成モーダル・マイルストーン作成モーダル・タスク作成 (⌘Enter 注記がその下)
- キャンセル的な控えと対 — 設定モーダル (右下・固定で常時表示)・文書更新 (左下・⌘Enter 注記がその下)・マイルストーン編集 (左下・別のアクションがその下)・タスク作成ポップアップ (左下)・タスク編集 (右上)

ユーザーが導入したい規則: **保存の控えを固定で常時表示する場合は、表示領域の下へ幅いっぱいの行を作り、その中で中央に置く**。適用先として 設定モーダル と タスク編集 を名指ししている。

```
   +----------------------------+
   |   表示領域（スクロール）   |
   +----------------------------+
   |   [キャンセル][保存する]   |
   +----------------------------+
```

**決定先行**: doc-11 §7 が下部操作行の条件を「下書きを書いて出る出口を併せ持つモーダルだけ」と定めており、位置は定めていない。位置の規則を §7 が持つのか別節を立てるのか、また固定しない場合 (左下単独) の規則も同じ節で決めるのかを先に確定する。TASK-115 が `--modal-confirm-height` などの高さの定数を置いているので、行の高さはそこへ載る。
