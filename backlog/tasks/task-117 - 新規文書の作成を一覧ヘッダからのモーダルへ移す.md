## 実装

- `ProjectDetail.svelte`: `createOpen: "document" | "milestone" | null` 1 値で層を持つ
  （被せ層 は 1 枚だけを構造で保証する）。`listHead` snippet を 2 区画で共有。
- 新しい prop `onoverlay` でシェルへ層の有無を伝える。シェルは `modalOpen` に折り込み、
  メニュー・ポップオーバーを下ろし、背後の未応答の破棄前確認を失効させる（doc-11 §7）。
  **`raiseModal` と違ってフォーカスは動かさない** — この関数は層がマウントして × へ
  フォーカスを取った後の effect から走るので、ここで `focus()` すると開く前の操作へ戻すのでは
  なく、上がっている層の外へフォーカスを出すことになる。
- `dirty` から `hasDocCreateInput` / `hasMilestoneAddInput` を外した。入力は層と一緒に消えるので、
  画面を離れられるどの瞬間にも残っていない（節を残すと常に false の節になる）。
- lucide の `plus` を追加（`lucide-react` v1.17.0 の `plus.mjs` を実際に取得して座標を確認。
  path 2 本で要素種別の列挙は増えない）。doc-11 §2.4 の**可視の文言を持つ控えの中のアイコン**
  なので `aria-label` は与えない。
