## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
画面設計案 07 はヘッダ左上に「← スイムレーン」を置き、その右にプロジェクト名・slug・件数を並べる。現在の実装は ProjectDetail.svelte の件数表示より後ろに戻るボタンを置いており、復帰導線が見つけにくい。あわせて「このプロジェクトのレーンへ」が機能していないように見える問題を直す。原因は着地が scrollIntoView({block:'nearest'}) だけで、対象行が既に視界内にあると何も動かず、行が視界外でもレーンヘッダ行が非スティッキーなため着地位置が分からないこと。
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 「← スイムレーン」がヘッダ左上にあり、画面設計案 07 と同じ配置になっている
- [ ] #2 対象行が行非表示だった場合も戻した上で着地する（現在の挙動を維持する）
- [ ] #3 「このプロジェクトのレーンへ」で戻ると、対象のレーンヘッダ行がスクロール領域内に入り、対象行に一時的な強調が付く
