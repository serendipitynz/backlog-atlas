## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
**doc の欠落**（TASK-119 / PR #69 のレビュー [P2] で判明）。

`App.svelte` の `raiseModal()` は共通入口のモーダルを上げる前に、メニューと値一覧ポップオーバーを閉じる。`openMenu()` も同じくポップオーバーを閉じる。つまり **被せ層は同時に 1 枚しか立てない** という規則が実装にある。この規則は `raiseModal` のコード註にしかなく、`backlog/` 配下のどこにも書かれていない（doc-7 §2.1 は被せ層を列挙するが、同時に何枚立てるかを述べていない）。

AGENTS.md の「decision/doc が契約」を満たしていない状態であり、TASK-119 が doc-7 §5.2 で直したのと同じ形の欠落である。TASK-119 はポップオーバー側からこの規則に依存する文（「別の被せ層を上げる操作」が閉じる契機の 1 つ）を §5.2 へ書いたので、規則そのものの置き場が要る。

**置き場は doc-7 §2.1**（被せ層の列挙を持つ節）。この規則が支えているものも併せて書く — Escape（割り当て一覧の `closeOverlay`）が「開いている層」を 1 つに定められるのは、2 枚立たないことが前提だからである。

**TASK-117（新規文書の作成を一覧ヘッダからのモーダルへ移す、m-2・決定先行）が同じ §2.1 の被せ層列挙を触る**ので、ユーザーの判断でそちらへ合流させてもよい。
