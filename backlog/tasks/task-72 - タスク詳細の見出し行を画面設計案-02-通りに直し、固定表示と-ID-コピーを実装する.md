- **見出し行の構成**は、AC #1 の判定基準が doc-12 §3 に転記されていなかったため、ユーザーが画面設計案 02 の原文を提示し、doc-12 §3 へ転記を足してから実装した。
- **原文から意図的に 1 点外れる**: assignee を本文側の区画へ出し、その空きで `日付` 1 セルを `created`/`updated` の 2 セルへ割いた (ユーザー指示)。doc-12 §3・doc-8 §3 の両方に記録。ファイルパスは原文の属性表に無いので外れではない。

## 実測 (WebKit・Chromium、1280x800、`_sandbox/detail-check/`)

- 見出し: 併置 **133.06 / 135.11px (16.6 / 16.9%)**、モーダル **153.86 / 156.22px**、全面 同値 **(19.2 / 19.5%)**。改修前は 211〜239px・26.4〜29.9%。
- 属性表は 4 条件とも **3 段**を保つ (折り返していない)。編集中の見出しは 157.78〜188.69px (19.7〜23.6%) で属性は 3 段のまま。
- スクロール後もパネル上端との**隙間 0px** (モーダルは自身の枠 1px)、ID は常に箱の中。
- コピーの控え **21.59 x 21.59px**、図形 **12px**、`textContent` 空、ID との間 5.59px。押下で path 1 → 2、色が `--info` の実値ちょうど (light `#21648f`、dark `#66acdc`)、フェード中も 2 path のまま、収束後に地の色へ復帰。4 倍解像度の画像で両テーマとも tick が潰れずに読めた。

## 実測が見つけた欠陥 2 件 (テストでは緑のまま通っていた)

- `transition: color` を控えに常設すると**表示テーマの切替まで巻き込む**。フェードは `.fading` にだけ持たせる形へ直した。
- **`position: sticky` に負の上マージンは効かない** (静的位置で決まるため)。パネル上端との間に 9.6px の隙間が残り、縮退帯がそこを通って見出しの上に出た。パネルの上 padding を 0 にし、見出しがそれを持つ形へ直した。左右の負マージンは正しい。

## レビューが見つけた欠陥 (PR #55、6 ラウンド)

- **[P2] 常設の `role="status"` を sticky な `<header>` の直接の子に置いていた**。`.heading` のコード註自身が「変わる文は帯の外」と書いており、註が正しく実装が誤っていた。指摘より範囲を広げ、同じ形の要素 4 つ (既定書き込みの拒否・セル端の理由・ID を作れない理由・ファイル不明の警告) も帯の外へ出した。**空の live region が `gap` を 1 つ消費していた** — 見出し 133.06 → 128.27px の差 4.79px がそれで、静止状態の 1 枚しか測っていなかったため実測でも気づけていなかった。`display: none` では消していない (アクセシビリティツリーからも外れ、ツリーに無い live region は埋まっても読み上げられない)。無言のときだけ flow から外す形にした。
- **[P3] `detail.ts` 冒頭の対応表が旧見出し構成のままだった**。画面の構成を変えたらこの表も必ず一緒に直す。TASK-73・77 も同じ表を触る。
- **[P3] 前後移動の控えについて `aria-label` と `title` を取り違えていた**。`aria-label` は `title` に優先するので、群の名前は名前ではなく説明 (description)。マークアップは正しく、説明する言葉だけが誤っていた。
- **契約を変えたのに旧契約を主張する記述を消し切れず、同じ欠陥を 3 回作った** (round 3・4・5)。doc-8 §2.2 の位置表示の契約が 1 つ目の箇条書きに残る / 同じ箇条書きの前半と後半が矛盾の両側を主張する / `swimlane.ts` の `UNMAPPED_LABEL` のコメントが位置表示を利用先に挙げたまま。最後の 1 件は grep の出力に入っていたのに読まずに「掃き出した」と報告した。
