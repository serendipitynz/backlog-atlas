# 画面設計案の引用箇所転記

## 1. この文書の役割

**画面設計案** とは、Atlas の画面設計の入力としてリポジトリ外に作られた HTML プロトタイプ束を指す。Claude Design（claude.ai/design）のハンドオフ束として書き出されたもので、`01 スイムレーン全景`〜`07 プロジェクト詳細` の 7 本と、テーマ変数を持つ `themes.css` からなる。**リポジトリの外にあるため、このリポジトリの読者は開けない。**

doc-7・doc-8・doc-10・doc-11 と decision-12・decision-13 は、この画面設計案を反映した結果であり、反映後の正本はそれらの文書である。本書はその手前を埋める。すなわち、**リポジトリ内の文書が画面設計案から引いている事実を、原文の値のまま写す**。読者が「設計案 05 が示した色値」「04 の割当表」を確かめたいとき、リポジトリの外へ出ずに本書で足りるようにするためである。

本書は転記であって決定ではない。値の是非や採否は、引用している側の文書（doc-7・doc-11・decision-12 など）が定める。両者が食い違う場合は引用している側が優先する。本書の各節には、原文で改訂対象として名指しされた契約も併記する。

## 2. 05 配色と契約

### 2.1 印チップの構造

現行は「族の色でベタ塗り + 白文字」で、`#b8860b` 上の白文字は約 2.8:1 しかない。設計案はこれをやめ、次の構造へ変える。

- 文字 = 族の色
- 背景 = 族の色 12% 混色（`color-mix(in srgb, <族の色> 12%, transparent)`）
- 枠 = 族の色 45% 混色

コントラストは「族の色 対 ページ背景（12% 混色後）」で決まる。ライト・ダークとも同じ規則で成立し、テーマは色値だけを差し替えればよい。

族の判別は色相と文言の二重化による。縮退 = 黄土 / 版ずれ = 紫 / 照合不能 = 灰青 / 読取不能 = 赤 / 通知 = 青。「正常な不在（—）」と「Type 未設定」には引き続き色を与えない（不透明度と破線枠のみ。decision-6 を維持）。

コントラスト比の計算規則は WCAG の相対輝度比で、12% 混色後の背景に対する実計算値。目標は 4.5:1 以上、下回るセルに `▲` を付ける。原文は表示時に計算しており固定値を持たないため、セルごとの比は本書には写さない。

### 2.4 テーマ切り替えの方式

- 現行の `:root { --mark-* }` 一箇所定義を、`[data-theme="…"] { --bg / --fg / --line / --mark-* / --info }` のテーマブロック群へ拡張する。コンポーネントは従来どおり変数名だけを参照し、色を選ばない（decision-6 の構造は不変）。
- 各テーマブロックが `color-scheme: light` / `dark` を宣言し、フォームコントロールとスクロールバーの明暗も追従させる。`canvas` / `canvastext` の直接参照は `--bg` / `--fg` 経由へ置き換える。
- 収録テーマは上表の 10 組。切り替えは設定で永続し、既定は OS の明暗に追従して Atlas Light / Atlas Dark を選ぶ。
- priority の現行色（high = `#c0392b`・medium = `#b8860b`）は読取不能・縮退と同色で族を汚染するため、無彩の濃淡 3 段へ置き換える。

## 3. 04 カードサイズ

YouTrack の S/M/L/XL/TV を 3 段階に絞った案。サイズはユーザー設定として永続（ボード単位ではなくアプリ単位。単一画面のため）。状態の印（縮退・版ずれ・保存区分・生 status）はどのサイズでも落とさない。

項目割当表（原文の見出しは「doc-7 §3 の改訂案」）。

| 項目 | S | M（既定） | L |
|---|---|---|---|
| 横断タスクID | ○ | ○ | ○ |
| priority | ○ | ○ | ○ |
| 状態の印（縮退・版ずれ・保存区分・生 status） | ○ | ○ | ○ |
| title | 1 行 | 2 行 | 3 行 |
| Type チップ | — | ○ | ○ |
| 通常ラベル | — | — | ○ |
| assignee | — | — | ○ |

- 現行の固定項目表は「M ≒ 現行 − ラベル・assignee」「L = 現行どおり」「S = 識別と印のみ」の 3 段へ置き換える。
- 通常ラベルを L 限定にする根拠は、数が可変で高さが読めない項目がカードの行数保証を壊すため。
- 状態の印を全サイズで保持する根拠は、落とすと「問題があるタスクが正常に見える」ため。生 status は未対応列でのみ付くため、S でも密度を崩さない。

Type チップと通常ラベルチップの視覚的分離は、角丸半径の差だけでは弱いとして、形・塗り・太さの 3 点を変える。Type は塗り + 太字 + 角丸 3px（未知 = 実線輪郭、未設定 = 破線・色なし）、通常ラベルは輪郭のみのピル（角丸 999px）+ 細字 + muted。priority は族の色を借りず、high = `--fg` 反転ベタ、medium = 実線輪郭、low = 細線輪郭 + muted。

## 4. 01 スイムレーン全景

- Tweaks のカードサイズ既定値は **L**（原文のラベルは「L（既定・ラベルと担当まで）」）。上の 04 割当表は M を既定としており、**画面設計案の内部で一致していない**。この不一致の裁定は doc-7 §3 が行う（doc-7 は M を採り、既定値の正本を doc-7 とする）。
- 設定モーダルが挙げる項目: Backlog ルート（省略時は `<プロジェクトルート>/backlog`、`config.yml` と `tasks/` が読めることを条件とする）、プロジェクト slug（既定はディレクトリ名から導出し小文字化）、テーマ、既定の保存区分（`active + draft`）、チェックボックス「起動時に全ルートを読み直す」。
- 継続検出が動いていない行には帯で「変更監視が動いていない行があります」と出し、レーンごとの「再読込」で読み直せるようにする。

## 5. 02 タスク詳細3配置

- 詳細の配置は併置サイドバー・中央モーダル・全面シングルビューの 3 種。既定の配置ボタンに下線印を付け、選択はアプリ設定へ保存して再起動後も保つ。
- 前後移動は同一レーンセル内の ↑↓ で、3 配置共通で見出しに置く。未保存入力があれば破棄前確認を通す。
- 外部エディタ区画の起動口は「$EDITOR で開く」と「OS の関連付けで開く」の 2 つ。References は最後の 1 件を削除できない旨を注記し、削除は外部エディタへ誘導する。
- 縮退表示は印がある時のみ 3 配置とも常設。状態遷移・外部エディタの区画は併置とモーダルで折畳み（既定閉）、全面で常設。
